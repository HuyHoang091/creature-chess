# Economy Guide - Creature Chess

## Gold Mechanics
- **Income per round**: Base income + interest (1 gold per 10 saved, max 5)
- **Win/loss streak**: Bonus gold for consecutive wins or losses
- **Sell units**: Get back their cost

## Phase Strategy

### Early Game (Rounds 1-3, Creep Rounds)
- **Goal**: Collect items, save gold
- **Don't reroll** — save every gold you can
- **Buy cheap units (cost 1-2)** that can win creep rounds
- **Pick up pairs** — if you see 2 of the same unit, buy both for potential upgrade

### Mid Game (Rounds 4-7)
- **Economy threshold**: Try to reach 50 gold for max interest (5 gold/round)
- **Level to 5-6** to increase board size
- **Start building synergies** — commit to 1-2 element traits
- **Reroll sparingly** — only if you're 1 unit away from a key upgrade

### Late Game (Rounds 8+)
- **Level to 7-8** for cost 4-5 units
- **Spend down to 50** each round on rerolls if needed
- **Finalize team comp** — sell off units that don't fit synergy
- **All-in if low HP** — spend everything to find key units before losing

## Decision Framework

### When to Save (Econ)
- HP > 70% — you can afford to lose some rounds
- No critical upgrades available
- Below 50 gold — interest breakpoint matters

### When to Spend
- HP < 40% — you're in danger, need to power up now
- 1 unit away from a 3-star upgrade
- Above 50 gold with clear upgrade path
- Contested — other players are buying your units

### Level vs Reroll
- **Level up** if you need higher-cost units (4-5 cost carries)
- **Reroll** if you need specific lower-cost units to complete upgrades
- **General rule**: Level > Reroll in most situations

## Common Mistakes
1. **Rerolling below 50 gold** — kills your economy
2. **Holding too many bench units** — sell what you won't use
3. **Forcing a comp** — adapt to what the shop gives you
4. **Ignoring interest breakpoints** — always try to end round at 10/20/30/40/50 gold
