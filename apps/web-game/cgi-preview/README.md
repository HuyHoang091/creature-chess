# CGI Preview

Open `majestic-background-preview.html` directly in a browser to preview the background as a standalone scene.

Files:
- `majestic-background-preview.html`: standalone preview page
- `majestic-background-preview.css`: visual styling for the preview shell
- `majestic-background-preview.js`: animated canvas scene
- `desktop-battlefield-preview.html`: standalone in-match battlefield preview
- `desktop-battlefield-preview.css`: layout + styling for the DesktopGame-style preview
- `desktop-battlefield-preview.js`: animated arena background for the board scene
- `desktop-battlefield-*-preview.html`: trait variants for fire, earth, wood, metal, arcane, valiant, cunning
- `desktop-battlefield-gallery.html`: quick launcher page for all trait variants

This preview is intentionally separate from the game so the background can be reviewed before integration.
